# Anne Soru Bombardımanı Simülatörü

## Resmi Tanım

Bu proje, Türk toplumunun en güçlü doğa olayını dijital ortama taşımaktadır: **Anne Soru Yağmuru**.

Bilimsel araştırmalar (kaynak: herkesin deneyimi) göstermektedir ki bir Türk annesi, saniyede 2.7 soru sorma kapasitesine sahiptir. Bu kapasite açlık, evlilik, kilo, iş ve komşu dedikodusu konularında üstel olarak artmaktadır.

## Nasıl Çalıştırılır?

```bash
python anne.py
```

**Uyarı:** Bu programı çalıştırmadan önce psikolojik destek hattını hazır bulundurun. Ctrl+C ile çıkış yapabilirsiniz ancak anneniz bunu "telefona bakıyorsun" olarak yorumlayacaktır.

## Özellikler

- Sonsuz döngü (gerçek anneler gibi)
- Seviye sistemi (sorular zamanla daha yüksek sesle sorulur)
- Rastgele ek yorumlar
- Gerçekçi bekleme süreleri
- Kaçış imkânsız

## Copilot ile Yapılan Görüşme

**Ben:** Copilot, bu kodu daha da acımasız yapabilir miyiz?

**Copilot:** Evet. `while True` yerine `while annen_yasıyor` koymayı öneriyorum. Ayrıca soruların içine "komşu teyze de aynı şeyi sordu" eklemek etkiyi %340 artırır.

**Ben:** Teşekkürler Copilot, sen de bir anne olabilirsin.

**Copilot:** Hayır, ben sadece kod tamamlarım. Anne olmak için özel bir süper güç gerekir.
